## Sobre mim

Sou desenvolvedor em formação com foco em aplicações web, mobile e soluções inteligentes utilizando Inteligência Artificial.

Tenho experiência prática no desenvolvimento de aplicações com **React, React Native utilizando Expo, JavaScript e PHP**, além da criação e consumo de **APIs REST**, integração entre sistemas e utilização de bancos de dados relacionais e não relacionais.

Também já trabalhei com **chatbots, agentes de IA e assistentes inteligentes**, aplicando Inteligência Artificial em automações de fluxo, classificação de informações, análise de texto e geração de relatórios.

No ciclo de desenvolvimento, tenho experiência com testes em ambiente de homologação, code review, manutenção e evolução de aplicações, criação de dashboards, design responsivo e gerenciamento de deploys em nuvem.

Atualmente curso **Tecnologia em Desenvolvimento de Software Multiplataforma** na **Fatec Ogari de Castro Pacheco**, em Itapira, no período **noturno**.
