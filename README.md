Sobre mim

Sou desenvolvedor em formação, com foco em aplicações web, mobile e soluções inteligentes utilizando Inteligência Artificial.

Tenho experiência prática com React Native (Expo), React, JavaScript, PHP, APIs REST, bancos de dados e automações com IA, incluindo o desenvolvimento de chatbots, agentes e assistentes inteligentes integrados a aplicações e serviços externos.

Também tenho experiência no ciclo de desenvolvimento de software, participando da criação e evolução de interfaces, integrações entre sistemas, testes, correções, code reviews e deploy de aplicações em nuvem.

Busco construir soluções modernas, bem estruturadas e úteis, sempre com atenção aos detalhes, organização, pensamento crítico e foco na resolução de problemas.
